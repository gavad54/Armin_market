# آرمین مارکت — نسخه اولیه اندروید

این مخزن اکنون یک پروژه اولیه Android/Kotlin/Jetpack Compose دارد و GitHub Actions هنگام تغییرات شاخه `main` تلاش می‌کند APK آزمایشی بسازد.

## وضعیت فعلی
- رابط اولیه فارسی و راست‌به‌چپ‌پذیر
- جست‌وجوی محلی در دسته‌بندی‌های نمونه
- نوار ناوبری نمایشی
- Backend مستقل MVP برای حساب خریدار/فروشنده، درخواست خرید و استعلام قیمت در پوشه `backend/`
- گردش ساخت خودکار APK آزمایشی

## محدودیت‌های مهم
رابط Android هنوز به Backend جدید متصل نشده و داده‌های کالا/فروشنده در خود برنامه همچنان نمونه نمایشی هستند. Backend مستقل در این شاخه API آزمایشی ثبت‌نام، درخواست خرید و پیشنهاد فروشنده را دارد؛ اما هنوز به Android یا محیط عملیاتی متصل/منتشر نشده است. MFA، تأیید ایمیل، بازیابی رمز، rate limit، PostgreSQL عملیاتی، پشتیبان رمزنگاری‌شده و Restore واقعی، پنل مدیریت و پرداخت وجود ندارند. هیچ پرداخت یا سفارش واقعی انجام نمی‌شود.

## دریافت APK آزمایشی
1. به زبانه **Actions** در GitHub بروید.
2. اجرای **Android APK Build** را باز کنید.
3. پس از پایان موفق، بخش **Artifacts** را باز کنید.
4. فایل `armin-market-debug-apk` را دریافت کنید.

APK ساخته‌شده در این گردش، نسخه debug برای آزمایش است و نسخه امضاشده برای انتشار عمومی محسوب نمی‌شود.

## فناوری
- Android / Kotlin
- Jetpack Compose / Material 3
- Gradle / GitHub Actions


## Backend API (MVP)

برای وضعیت API، روش اجرای محلی، Docker و محدودیت‌های انتشار به [راهنمای Backend](backend/README.md) مراجعه کنید. این سرویس مستقل هنوز به اپ Android متصل نشده است.
