# آرمین مارکت — نسخه اولیه اندروید

این مخزن اکنون یک پروژه اولیه Android/Kotlin/Jetpack Compose دارد و GitHub Actions هنگام تغییرات شاخه `main` تلاش می‌کند APK آزمایشی بسازد.

## وضعیت فعلی
- رابط اولیه فارسی و راست‌به‌چپ‌پذیر
- جست‌وجوی محلی در دسته‌بندی‌های نمونه
- نوار ناوبری نمایشی
- گردش ساخت خودکار APK آزمایشی

## محدودیت‌های مهم
این نسخه هنوز فروشگاه تجاری کامل نیست. کالاهای واقعی، حساب کاربری، پایگاه داده، API سرور، مدیریت فروشندگان، سبد خرید عملیاتی، پرداخت، سفارش و پنل مدیریت متصل نشده‌اند. هیچ پرداخت یا سفارش واقعی را انجام ندهید.

## دریافت APK آزمایشی
1. به زبانه **Actions** در GitHub بروید.
2. اجرای **Android APK Build** را باز کنید.
3. پس از پایان موفق، بخش **Artifacts** را باز کنید.
4. فایل `armin-market-debug-apk` را دریافت کنید.

APK ساخته‌شده در این گردش، نسخه debug برای آزمایش است و نسخه امضاشده برای انتشار عمومی محسوب نمی‌شود.

## فناوری
- Android / Kotlin
- Jetpack Compose / Material 3
- Gradle / GitHub Actions
